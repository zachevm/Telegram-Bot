# Telegram Crypto Bot

This bot fetches the latest token information from DexScreener and sends updates to a Telegram chat every 15 minutes. It also filters out devs who have been known to rug coins, putting them in a blacklist.
## Features
- Fetches live token data.
- Sends updates directly to Telegram.
- Built with Python and integrates with the Telegram Bot API.

## Usage
1. Clone the repository.
2. Set up the environment as described in the main.py file.
